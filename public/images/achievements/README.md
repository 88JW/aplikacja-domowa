# Grafiki osiągnięć

Tutaj wklejaj ikony i ilustracje osiągnięć HomeApp.

Zalecenia:

- format: SVG, WebP albo PNG,
- najlepiej kwadratowe proporcje 1:1,
- zalecany rozmiar PNG/WebP: 512 × 512 px,
- przezroczyste tło,
- nazwy małymi literami, bez spacji i polskich znaków,
- przykładowa nazwa: `poranny-rozruch.webp`.

Plik `poranny-rozruch.webp` będzie dostępny w aplikacji jako:

```text
/images/achievements/poranny-rozruch.webp
```
