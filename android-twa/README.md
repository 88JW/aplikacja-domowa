# HomeApp dla Androida

Projekt generowany przez Bubblewrap jako Trusted Web Activity.

- pakiet: `pl.miasoftware.homeapp`
- minimalny system: Android 8.0 (API 26)
- adres startowy: `https://homeapp.miasoftware.pl/tablet`
- dystrybucja: ręczna instalacja podpisanego APK

Plik `homeapp-release.jks` oraz `signing.properties` są prywatne i nie mogą być
publikowane. Oba pliki trzeba zachować w kopii zapasowej, ponieważ są wymagane
do podpisywania przyszłych aktualizacji.

Gotowy plik instalacyjny: `app-release-signed.apk`.
